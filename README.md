# 🤖 Smart Plant Watering System

A hardware/software side project built with Raspberry Pi, C++, and Linux.

Starting with GPIO-controlled pump automation, this project will gradually evolve into a complete smart plant care platform featuring:

- 🌱 Soil moisture sensing
- 💧 Automated irrigation
- 🌐 REST API
- 📈 Time-lapse growth monitoring
- 📷 Computer vision for plant health detection

**Why?**

Inspired by a recurring real-world problem: I often forget to water my plants while traveling—or sometimes overwater them when I'm home. After losing one too many plants, I decided to build a system that not only automates watering but also helps me better understand how my plants grow over time.
